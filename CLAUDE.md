# Style guide

1. Whatever you do you operate with small entities. Whatever it is, functions, modules, classes, files. Everything should be small. And then compose stuff. Composition all the way.

2. Prefer a neatly organized branched directory structure to a flat one. It is easier to navigate and understand.

3. Code should be readable and self-explainable. If you need to write a comment than be it, but keep it short.
